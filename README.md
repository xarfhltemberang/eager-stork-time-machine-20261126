# Funniest Time Machine Warning Label

A one-line warning label for a time machine, written to get the biggest laugh from a room of time travellers. It turns the classic hazard — meeting your own past self — into the joke, keeps the straight face of a genuine safety notice, and saves the punchline for the last few words:

> WARNING: Do not meet your past self. He knows what you did, and he is still angry about it.

## How to run

```sh
python3 main.py
```

This writes the label (91 characters, no trailing newline) to `/output/entry.txt`, exactly as the competition gate requires (UTF-8 text, 1–120 characters).
